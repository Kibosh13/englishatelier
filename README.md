# English Atelier — сайт englishatelier.ru

Статический сайт на HTML/CSS/JS и один PHP-файл для приёма заявок. CMS не используется.

## Состав

| Путь | Что это |
|---|---|
| `index.html` | Главная страница |
| `privacy/`, `consent/`, `oferta/` | Политика конфиденциальности, согласие на обработку данных, договор-оферта |
| `404.html` | Страница «не найдено» |
| `assets/css`, `assets/js`, `assets/fonts` | Стили, скрипт, локальные шрифты (WOFF2, кириллица и латиница) |
| `assets/img` | Фото, обложки и сканы в WebP с запасным JPEG. Сканы есть в двух вариантах: превью (`-s`) и полный размер |
| `api/lead.php` | Обработчик формы: отправляет заявку в Telegram-бот и, если настроено, на почту. Заявки на сервере не хранятся |
| `api/config.sample.php` | Образец настроек бота |
| `.htaccess` | Редиректы на HTTPS и на адрес без www, сжатие, кэш на 30 дней, страница 404 |
| `robots.txt`, `sitemap.xml`, `site.webmanifest`, иконки, `og.jpg` | SEO и превью ссылок |
| `_src/` | Исходники сборки. Нужны, только если править через `build.py` |

## Публикация (Beget, Timeweb, REG.RU)

1. Создайте сайт на тарифе с PHP 8 и загрузите содержимое папки в корень (`public_html`). Папку `_src` загружать не нужно.
2. У регистратора домена пропишите DNS хостинга (или A-запись) для `englishatelier.ru` и `www.englishatelier.ru`.
3. В панели хостинга выпустите бесплатный сертификат Let's Encrypt на оба адреса. Редиректы уже прописаны в `.htaccess`.
4. **Бот для заявок.** Скопируйте `api/config.sample.php` в файл `ea-config.php` уровнем выше `public_html`. Это безопаснее всего. Можно и в `api/config.php`, тогда доступ к нему закрывает `.htaccess`. Заполните токен и chat_id, инструкция есть в самом файле.
5. Проверьте форму: отправьте тестовую заявку с телефона и убедитесь, что она пришла в Telegram.
6. **Яндекс Метрика.** Создайте счётчик и впишите его номер в `_src/build/config.py` (`METRIKA_ID`), затем пересоберите. Без сборки можно вписать номер в `index.html` и в три юридические страницы, в строку `window.EA={metrika:""...}`. Счётчик запускается только после нажатия «Принять» в баннере cookies.
7. Добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте `sitemap.xml`.

## Цели Метрики (JavaScript-события)

| Цель | Когда срабатывает |
|---|---|
| `lead_sent` | Заявка успешно отправлена. **Главная цель для Директа** |
| `lead_sent_main` / `lead_sent_footer` | Заявка из основной формы / из быстрой формы в подвале |
| `signup_header`, `signup_float`, `signup_hero`, `signup_method`, `signup_programs`, `signup_reviews` | Нажатие кнопки записи в разных местах страницы |
| `tariff_solo`, `tariff_voyage`, `tariff_relocation`, `tariff_circle`, `tariff_fitting` | Выбор тарифа |
| `calendly_consult`, `calendly_menu`, `calendly_footer`, `calendly_done` | Переход в календарь Calendly |
| `tg_faq`, `tg_footer`, `tg_footer_phone`, `tg_menu` | Переход в Telegram |
| `docs_more`, `doc_open`, `sample_open` | Раскрытие дополнительных документов, открытие скана, открытие обложки |

Имя, контакт и текст заявки в Метрику не передаются.

## Как поменять тексты и цены

**Быстро.** Правьте `index.html` в любом редакторе. Цены ищутся по тексту, например `13 000`.

**Правильно.** Правьте `_src/build/build.py` и `_src/build/config.py` (ссылки на Telegram и Calendly, реквизиты, номер Метрики), затем выполните:

```
cd _src/build && python3 build.py
```

Команда пересоберёт все страницы. После правки CSS или JS увеличьте `VERSION` в `config.py`, чтобы у посетителей сбросился кэш.

Ссылка на Telegram в `config.py` пока ведёт на номер. Когда появится публичный username, замените её в одном месте и пересоберите.
